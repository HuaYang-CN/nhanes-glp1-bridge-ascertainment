# Known limitations

The original historical R 4.6.0 runtime/session and original restricted-fasting n742 generating script are unrecovered. This candidate implements the verified R 4.5.1 reconstruction and G2 HbA1c<6.5/FPG<126 sensitivity. Numerical agreement does not recover historical provenance. Public age80 topcoding remains; assumed age85 is illustrative. A laboratory range or single reduced eGFR is not a clinical diagnosis or CKD chronicity. D2 assumes a possible Borderline history signal; it does not establish diagnosed prediabetes. Paired tests are exploratory/post hoc, with nominal nonsimultaneous CIs and a two-P-value Holm family. No corrected subgroup hypothesis test is added; historical subgroup test outputs remain unavailable. Nonpositive represented-domain degrees of freedom retain a point/SE with non-estimable CI under the adopted policy.

Final publication Word/R1 table layout recreation is optional and currently not implemented by this runner. Fresh full-precision source tables S1-S7 and six figure panel source datasets are generated from calculated results. The optional --figures switch exports scientific PDF/PNG/JPG composites without changing protected journal figures; generation and numerical-source consistency do not certify final production layout or byte identity. Author approval, release/license permission, actual reviewer access and public archiving are separate from a local successful test.
